# Arthryme Private Limited — Business Solutions Website

A responsive business website developed for Arthryme Private Limited as an interview project. The website presents the company's services and provides ways for visitors to submit enquiries and quote requests.

## Live Demo
- **Website:** https://arthryme-website.vercel.app/
- **GitHub Repository:** https://github.com/Abhishekjha2568/arthryme-website

## Features

- Responsive business website
- Services showcase across multiple business sectors
- Contact form for visitor enquiries
- Quote request form
- Admin login and dashboard
- Search and status filtering for quote requests
- Quote request status management
- Dark Mode with saved preference
- Solution Finder
- FAQ-based chatbot for common questions

## Services Covered

- Manpower
- IT Hardware & Digital Solutions
- School & College ERP
- Digital Marketing
- Podcasting
- Automobile & GPS
- Printing
- Grocery
- Furniture
- Industrial Solutions
